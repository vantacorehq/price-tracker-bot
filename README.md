Price Tracker Bot
Telegram bot that watches prices in real time and pings you the moment something changes.
Features
- Tracks product or crypto prices around the clock
- Instant Telegram alerts on price changes
- Lightweight local storage — no heavy infrastructure needed
Tech stack
Python · Requests · SQLite · Telegram Bot API
Status
Actively maintained. Custom price-tracking bots built for client needs.

## Usage

```bash
pip install -r requirements.txt
python price_tracker.py
```

Set your `BOT_TOKEN` and `CHAT_ID` at the top of `price_tracker.py` before running.
